# SCALA Pequeños Valientes

Aplicación educativa infantil independiente, en español, con TypeScript, Vite y Capacitor.

- Conserva los bytes del logotipo original SCALA y las identidades visuales aprobadas.
- Los personajes son Escalito, Lupi, Ana de morado, Luz de amarillo, Mateo y Roko de rojo.
- No añadas comentarios al código salvo petición explícita.
- Ejecuta Python desde este proyecto mediante uv.
- Usa procesos acotados y cierra servidores y navegadores al finalizar.
- Compila Android mediante GitHub Actions con JDK 21.
- Mantén el contenido infantil, los datos locales y el acompañamiento de adultos.
- No presentes la aplicación como tratamiento médico ni afirmes eficacia sin validación.
- Prueba el progreso, los límites de volumen, las narraciones, el PIN y la recuperación, la accesibilidad y el funcionamiento sin conexión.

Comprobaciones: npm run check; npm test; npm run build; npm run test:ui.
