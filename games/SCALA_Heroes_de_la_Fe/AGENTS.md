# SCALA Héroes de la Fe

Juego original de trivia en TypeScript, Vite y Capacitor para Android.

- Conserva los bytes del logotipo original SCALA.
- No añadas comentarios al código salvo petición explícita.
- Ejecuta Python desde este proyecto mediante uv.
- Usa procesos acotados y servidores que se cierren al finalizar; no inicies procesos en segundo plano.
- Usa GitHub Actions para la compilación nativa con JDK 21.
- Valida preguntas contra las referencias bíblicas y prueba progreso, recompensas, ayudas y juego sin conexión.

Comprobaciones: npm run check; npm test; npm run build; npm run test:ui.
