# Privacidad — SCALA Héroes de la Fe

Versión 1.0.0 · 9 de octubre de 2026

La aplicación Android funciona sin conexión. No crea cuentas, no usa analítica, no muestra publicidad y no envía datos a servidores. No tiene permiso de acceso a Internet.

El dispositivo guarda la experiencia, las monedas del juego, las rondas, las respuestas, los logros, los favoritos, los ajustes y los nombres opcionales del duelo. Estos nombres se usan únicamente para identificar los turnos locales; no se publican ni se envían a otros usuarios. El desafío diario usa la fecha del dispositivo.

La aplicación no solicita acceso a ubicación, contactos, cámara ni micrófono. El permiso de vibración permite un toque breve opcional; se desactiva en Ajustes. Si se activa la copia de seguridad de Android, el sistema puede incluir el progreso en ella según la configuración del propietario del dispositivo y del servicio de copia de seguridad.

El usuario puede reiniciar su progreso desde Ajustes mediante una confirmación. Se borran el avance, las rondas, los favoritos, los logros y los nombres del duelo; se conservan las preferencias de sonido. La desinstalación elimina los datos locales de la aplicación, sujeto al comportamiento de restauración de copias de seguridad de Android.

La aplicación no ofrece compras dentro del juego. Las monedas son ficticias, se ganan jugando y se usan para ayudas.

Para publicar esta política en una tienda, el titular debe añadir sus datos de contacto y alojarla en una URL pública propia. Esos datos no se han inventado en el proyecto.
